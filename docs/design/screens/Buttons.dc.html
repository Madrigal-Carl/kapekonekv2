Shared component

Button

One <Button> for every button and button-styled link in the app (storefront and dashboard). Props: variant, size, leftIcon / rightIcon (react-icons), iconOnly (needs aria-label), loading, disabled, fullWidth, as (button, Link, a). Radius 5px, weight 600, gap 8px.

VariantDefaultHoverFocusDisabledLoading
Solid · primaryvariant="solid"Main action on a page or drawer: Save, Add farm, Confirm order
Outlinevariant="outline"Secondary action next to a solid one: Cancel, Export CSV, Edit
Softvariant="soft"Low-emphasis actions inside cards: Message Liza, Open group chat
Ghostvariant="ghost"Inline/toolbar actions: Clear filters, Add tree group in a list
Dangervariant="danger"Confirming a destructive action in a modal: Archive, Reject, Remove
Danger outlinevariant="danger-outline"Starting a destructive action in a drawer footer: Reject, Cancel sale
Successvariant="success"Approve / complete: Approve farmer, Mark completed
Linkvariant="link"Text actions: View, See all, Forgot password—
